# Contributing

This repository exists primarily for public verification, evidence challenges, and replication reports.

Useful contributions include:
- reproducible verifier defects;
- evidence inconsistencies;
- mathematically grounded claim challenges;
- independent replication reports;
- documentation corrections.

Please use the provided issue forms before opening a pull request for material evidence changes.

TEMRAL may reject changes that would expose private implementation mechanics, customer data, credentials, or unsupported claims.
