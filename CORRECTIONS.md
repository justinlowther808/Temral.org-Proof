# Corrections and Withdrawals

TEMRAL does not silently rewrite material public evidence.

Classes:
- **Typo:** no interpretation change; normal commit.
- **Clarification:** wording-only change; changelog entry.
- **Material correction:** interpretation, metric, or evidence changes; new patch release plus correction notice.
- **Withdrawal:** evidence no longer trusted; original release remains visible and is marked withdrawn.
- **Supersession:** newer evidence replaces an older release without implying the older release was false.

Published release assets should not be overwritten in place.
