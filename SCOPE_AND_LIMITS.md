# Scope and Limits

This repository mirrors the bounded public evidence at https://temral.org/proof.

It supports:
- one flagship matched OpenAI GPT-5.6 Sol live pair with exact required-output preservation;
- exact-minute provider/account usage reconciliation for that flagship pair;
- six additional full matched pairs across OpenAI GPT-5.6 Terra and Anthropic Claude Sonnet 5;
- Strict99 reduction in every published replication pair.

It does not claim:
- universal performance across every workload;
- universal performance across every model or provider;
- guaranteed savings for every company;
- exact request-level dollar cost for the flagship pair;
- independent third-party reproduction;
- disclosure of private implementation mechanics.

The seven pairs are not seven copies of the same workload. Sol is the heavyweight flagship anchor; Terra/Sonnet is a six-pair retrieval replication set.
